Your task:
Given the current OptIR, selected strategy, precheck result, repair context, and current ordinary C source files, generate a local Patch JSON.

1. Generate a local patch plan only. Do not return complete source files here.
2. Target ordinary CPU C code only.
3. Do not use CUDA, cuBLAS, kernel launches, `__global__`, `__device__`, `__shared__`, `threadIdx`, `blockIdx`, or `cuda_*` APIs.
4. Preserve the public `cpu_gemm` signature:
   `void cpu_gemm(int M, int N, int K, float alpha, const float *A, const float *B, float beta, float *C)`.
5. Preserve row-major FP32 NN GEMM semantics.
6. Prefer local edits inside `SGPO_CPU_PATCH_KERNEL_BEGIN/END`.

9. If the selected strategy is `CPU.Tiling.RegisterBlock.*`, the patch must update register tile fields and plan multiple C accumulators kept in local scalar variables.
10. If the selected strategy is `CPU.Memory.PackA.*`, `CPU.Memory.PackB.*`, or `CPU.Memory.PackAB.*`, the patch must update `cpu_memory.pack_a`, `cpu_memory.pack_b`, and packing layout fields.
